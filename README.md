
## コンパイルと実行方法

プログラムのコンパイルおよび実行は、ターミナル（コマンドライン）から行います。
作業ディレクトリは `./ap26unit1` を想定しています。

### 1. コンパイル

まずは `ap26unit1` ディレクトリに移動し、ソースコードをコンパイルします。文字化けを防ぐため、エンコーディングは `UTF-8` を指定してすべてのパッケージをコンパイルしてください。

```bash
cd ap26unit1
javac -encoding UTF-8 ap26/*.java myplayer/*.java p26x08/*.java

```

### 2. プログラムの実行

コンパイルが成功したら、目的に応じて以下のコマンドを実行します。

#### 🎮 動的評価AIと静的評価AIの対戦

動的評価AIと静的評価AIを対戦させるテストプログラムを実行します。

```bash
java p26x08.EvalTester

```

#### 🧠 静的評価AIのパラメータ学習

静的評価AIのパラメータ（重み）を調整・最適化するための学習プログラムを実行します。

```bash
java p26x08.Trainer

```

#### 🧠 動的評価関数のパラメータ学習
動的評価AIのパラメータ（重み）を最適化するための学習プログラムを実行します。

```bash
java p26x08.Trainer2

```

## ⚔️ 汎用対戦ツール（MatchRunner）の使用方法

`MatchRunner` は、実行時に引数を指定することで、プログラムのソースコードを書き換えることなく任意のプレイヤー同士を対戦させることができる汎用ツールです。

### 基本的な実行コマンド

作業ディレクトリ `./ap26unit1` から、以下の形式でコマンドを実行します。

```bash
java p26x08.MatchRunner <Player1> <Player2> <対戦順数> <結果出力ファイルパス> <ログ出力ファイルパス>

```

### 引数の説明

| 引数 | 説明 |
| --- | --- |
| `<Player1>` | プレイヤー1のクラス名。パッケージ名（`p26x08.`）は省略可能です。 |
| `<Player2>` | プレイヤー2のクラス名。 |
| `<対戦順数>` | 実行する「順」の数。1順につき先手・後手を入れ替えて**合計2局**行われます（例: `5` を指定すると計10局）。 |
| `<結果出力ファイルパス>` | 勝敗、先後別の勝率、獲得勝ち点などを記録するテキストファイルのパス。 |
| `<ログ出力ファイルパス>` | 各ゲームの棋譜（各手の情報や思考時間）を記録するテキストファイルのパス。 |


### 出力ファイルについて

* **結果出力ファイル**
対戦の総括レポートが出力されます。総対局数・引き分け数、各プレイヤーの総勝利数と勝率、先手番（黒）/後手番（白）別の勝利数、大会ルールに準拠した獲得勝ち点の合計などが記録されます。
* **ログ出力ファイル**
各対局の詳細な進行状況が記録されます。実際に打たれた手や思考時間、エラーが発生した場合の詳細ログがここに出力されます。
